Selected Projects Demonstrating Solution-Development Capability

Vicmap M1 Validation Pipeline — Council property-update automation, open source · github.com/Maz2580/vicmap-m1-ai-pipeline

Built at Greater Shepparton to automate the fortnightly M1 cycle end-to-end: inbox monitoring for the Vicmap delivery, FME reload workspaces, Pozi Connect M1 generation, then validation of every row against the rates system (SQL Server) and Vicmap layers in ArcSDE. Deterministic rules settle clear cases; a language model reviews only ambiguous rows with strict-schema output; each row gets KEEP/REJECT with a reason and confidence for officer sign-off. Read-only database access by design · published security audit with critical findings fixed · CI on Windows & Linux · reusable by any Victorian council.

UMAMI — University of Melbourne · AI-assisted spatial query platform · geollm.idigitaltwin.org/UMAMI

Lead developer of a platform that lets non-technical staff and researchers ask spatial questions of PostGIS data in plain language, removing the GIS team as a bottleneck for routine queries. Integrates PostGIS, multi-provider LLMs with tool servers (MCP), CesiumJS 3D visualisation and IoT/MQTT sensor dashboards, with JWT authentication and role-based access; containerised and released through GitLab CI/CD.

Terrascout — Geospatial data scoping platform · terrascout.app

Architected an end-to-end commercial platform that turns a plain-English project brief into ranked satellite, aerial and LiDAR datasets with feasibility checks: FastAPI back end, React/TypeScript front end, PostGIS + pgvector, REST API, a CLI published on PyPI and an MCP server for AI assistants. Rules and embeddings run first and the LLM is called only below a confidence threshold; every AI agent has a deterministic fallback. 900+ automated tests · 23 providers / 29 sensors · health-gated CI/CD deploys.

UrbanMind — Urban scenario planning platform for Australian practice · urbanmind.terrascout.app

Integrated 36+ real datasets (ABS Census, Vicmap, PTV GTFS, building footprints) into 25 planning models — walkability, density, transit access, fiscal impact, urban heat and net-zero scenarios — parameterised to Plan Melbourne and Austroads. A U-Net surrogate trained on heat-simulation outputs gives near-instant results. One model library serves both a QGIS plugin for practitioners and a web platform for teams, deployed behind Cloudflare Tunnel with self-hosted CI.

GeoSpark — Open-source spatial AI library on PyPI · github.com/Maz2580/geospark

Designed a protocol and MCP tools that expose deterministic geodesic and topology computation (Shapely, pyproj) to any language model, plus a benchmark measuring models with and without tools — reporting negative results as well as gains. 535-question benchmark across 9 models · 779 automated tests · Apache 2.0 · manuscript under peer review.
